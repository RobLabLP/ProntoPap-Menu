# Pronto Papá — Menú digital

Versión premium mobile-first lista para GitHub Pages, QR y NFC.

## Publicar en GitHub Pages
1. Crea un repositorio nuevo en GitHub.
2. Sube **todo el contenido de esta carpeta** (index.html, styles.css, app.js y assets/).
3. Ve a **Settings → Pages**.
4. En **Build and deployment**, elige **Deploy from a branch**.
5. Selecciona la rama `main` y la carpeta `/root`.
6. Guarda y espera a que GitHub entregue la URL pública.
7. Usa esa URL para tu QR y para programar la etiqueta NFC.

## Carta original
El botón “Carta completa” intenta mostrar las fotos del proyecto anterior. Para que funcione en un repositorio independiente, copia las fotos originales de la carta dentro de `assets/` y actualiza las rutas del diálogo en `index.html`.
